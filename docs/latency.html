Each input device is measured on MiSTer at a 1 ms USB polling interval. An ATmega32U4 is wired directly to a button on the controller PCB and presses it at random times by pulling the button line to ground.

A custom MiSTer NES core raises a User I/O pin when the USB press arrives, and the microcontroller records the time from commanded press to detection. CSV captures are summarized in R: average, distribution, sample count and percentiles where raw captures exist.

MiSTer was chosen for deterministic FPGA GPIO and a low-latency USB stack; the results apply to any device that polls USB at 1 ms. Tester files, including the NES_Lag_Tester.rbf core, are in the inputlatency GitHub repository, and the results in the source spreadsheet.
